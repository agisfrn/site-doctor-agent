# Full-Site Scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `--mode full` (default): a concurrent code crawler that visits every page and checks every link, followed by Claude as an analyst; keep v2's Claude-led crawl as `--mode smart`.

**Architecture:** `browser.py` runs Playwright's async API on a background event-loop thread behind the existing sync `Browser` interface, adding `capture_many` / `fetch_many` / `fetch_text`. `crawler.py` discovers pages (robots.txt, sitemaps, links) and checks links. The tool-use loop, explanation call, partial-run handling and result building move from `agent.py` into `session.py` so the smart `Agent` and the new `Analyst` share them. `runner.py` picks the mode.

**Tech Stack:** as v2 (Python ≥ 3.11, anthropic 2.3, playwright async API, typer, rich, jinja2), plus `urllib.robotparser` and `xml.etree.ElementTree` from the standard library.

**Spec:** `docs/superpowers/specs/2026-10-29-full-scan-design.md` (builds on `2026-10-29-site-doctor-v2-design.md`)

## Global Constraints

- Branch `full-scan`, cut from `v2` at `ee1e252`.
- All v2 constraints hold: only `cli.py`/`ui.py` print; severities and scores come from code; tests need no API key or internet; run-relative forward-slash paths; ruff line length 100; commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Every Claude request: `client.beta.messages.create(..., betas=["server-side-fallback-2026-07-01"], fallbacks="default")`; crawl/analyst loop requests add `cache_control={"type": "ephemeral"}`.
- Modes: `full` (default; `--max-pages` default 200, max 1000) and `smart` (default 15, max 100).
- Defaults: `concurrency=4`; link checks ≤ 10 in flight overall and ≤ 2 per host; sitemaps followed 2 levels deep, ≤ 5000 URLs read; analyst ≤ 30 tool calls and ≤ 12 screenshots; overview ≤ ~6000 tokens (JSON ≤ 24 000 characters).
- Skipped extensions (never captured as pages): `.pdf .zip .jpg .jpeg .png .gif .webp .svg .mp4 .mp3 .doc .docx .xls .xlsx .ppt .pptx .csv .xml .json .txt`.
- Existing v2 tests keep passing unchanged, except where a task says it edits one.

**Spec deviation (deliberate):** the crawler fixture site is built in code (`tests/crawl_site.py`, served with `tests/servers.serve_routes`) instead of static files under `tests/fixtures/crawl_site/` — 30 generated pages and a redirect are easier to express as routes.

## Review Focus

1. **Endless URL variants** (`?utm_source=…`, `?fbclid=…`, `#section`): tracking parameters (`utm_*`, `fbclid`, `gclid`, `mc_cid`, `mc_eid`) are stripped in normalization so one page isn't crawled many times. Test in Task 3.
2. **`www.` vs bare host** (site at `https://a.com` linking `https://www.a.com/x`): treated as the same site for crawling. Test in Task 3.
3. **Huge sitemap** (6000 `<loc>` entries): reading stops at 5000 and the crawl still ends at `max_pages`. Test in Task 3.
4. **Sitemap listing another site's URLs**: those are not crawled. Test in Task 3.
5. **Ctrl+C mid-crawl**: the main thread polls the async engine every 0.2 s, so the interrupt lands within a second and yields a partial report. Test in Task 1 (`Browser._call` is interruptible) and Task 3 (crawler marks `interrupted`).

  - `crawler.group_pages(pages: dict[str, PageResult]) -> list[dict]` — applies `page_pattern`, then collapses the last segment to `*` for every parent path shared by ≥ 3 patterns (`/products/item-0` … `item-29` → `/products/*`); returns `{"pattern", "pages", "issues"}` sorted by pages desc, then pattern

- `normalize_url` additionally drops query parameters `utm_*`, `fbclid`, `gclid`, `mc_cid`, `mc_eid` (keeps the rest in original order).

Behaviour (spec § crawler.py, exact): robots via `fetch_text` + `RobotFileParser.parse(lines)` (non-int or ≥ 400 status → allow all; `config.ignore_robots` → allow all); seeds = start URL + sitemap URLs (`/sitemap.xml` and robots `Sitemap:` lines, index files followed 2 levels, ≤ 5000 `<loc>` read, namespace-agnostic `{*}loc`); BFS in batches of `config.concurrency`; captured pages run `run_page_checks`; `NotAPage` results become link statuses (not pages); `PageLoadError` → `basics.load_failure` (critical only for the start URL); origin from the first successful capture's `final_url`; after the crawl, every unique link not captured as a page goes through `fetch_many` in chunks of 50 (emitting `CrawlProgress` per chunk), broken ones → `links.link_finding(url, status, internal=same_site(...), found_on=first page that linked it)`; disallowed internal URLs are status-checked, not captured; `seo.check_site` once; `KeyboardInterrupt` anywhere → `stopped_reason="interrupted"` and return what's collected; page cap → `stopped_reason="page limit"`.
